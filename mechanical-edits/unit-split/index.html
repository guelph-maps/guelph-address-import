Batch 1 is the pilot, and there is a gate after it. The announcement promised “a pilot tile posted here with its counts and changeset before anything else moves.” Upload batch 1, post its count and changeset link to the thread, then carry on.
One box to tick before any link here works. JOSM → Preferences → Remote Control → “Open local files”. Checked on this machine when the batches were built: Remote Control is enabled, but that permission is not — so the buttons below will silently do nothing until you tick it. The permission is off by default in JOSM and has to be granted from JOSM’s own UI. If you would rather not, every button has a file name beside it: drag that file out of mechanical-edits/unit-split/batches/ into JOSM, or File → Open. Identical result.

Before the first one

  1. Be signed in as the account the announcement named — the same one the import uploads from.
  2. Each file carries its own changeset comment, source, source:license, mechanical=yes, bot=no and import_plan; JOSM fills the upload dialog in from them, so there is nothing to paste. created_by will read JOSM/… rather than the wiki table’s address-importer-friend — JOSM always stamps its own, and a value that cannot survive the upload was not worth writing. Worth a line when you post the pilot.
  3. Every object carries the version it was prepared against. If someone else has edited it since, the upload 409s and JOSM raises a conflict — that is the promised “skipped and re-examined rather than overwritten”, working. Discard ours and re-run build_batches.py --refetch later.
  4. Close each layer once it is uploaded. Thirty-six remote-control opens otherwise stack thirty-six layers, and JOSM uploads whichever one is active — not necessarily the one you just opened.
  5. Re-running build_batches.py --refetch renumbers everything: objects already fixed drop out of the fetch, the areas re-sort, and the pilot may move. The tick boxes are keyed by file name rather than number so they survive what they can, but expect to re-check. Anything already uploaded simply will not appear.
  6. Only addr:housenumber changes. Do not fold the addr:province campaign into these changesets — it is consented and revertable separately, and mixing them would make either revert take the other with it.
